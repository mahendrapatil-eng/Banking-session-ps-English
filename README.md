## ⚙️ Installation & Tally Connector Setup

### Steps:
1. Open the web application.
2. Open Tally and keep the required company **active**.
3. Download the **Tally Connector** from the web.
4. Install the connector.
5. Log in using your **registered email ID and password**.
6. Ensure the **Connector Port Number** matches the **Tally Port Number**.

### Upload Process:

  - Scanned PDF

- File should **NOT** be in RPT format.

## 📑 Statement Review & Explanation

### 🧾 Ledger Assignment

#### 1. One-by-One Ledger Assignment
- Assign ledger manually to each entry.

#### 2. Bulk Ledger Assignment
- Use **Description / Party Name / Keyword** to filter entries.
- Select multiple records and assign ledger together.
- This also helps in **rule creation** for future uploads.

---

### 🔁 Contra Entries

#### Cash Deposit
- Description: Self  
- Type: Receipt → Contra  
- Ledger: Cash  

#### Cash Withdrawal
- Description: Self  
- Type: Payment → Contra  
- Ledger: Bank / Company  

---

### 🏦 Bank-by-Bank Entries
- Type: Cash Deposit
- Ledger: Bank (e.g., Bank of Baroda)
- From the **second statement onward**, duplicate entries are avoided automatically.

---

### 🤖 Suggested Ledger
- When the next statement is uploaded, the system auto-assigns ledgers.
- Example: All **Shruti Medical** entries will get the same ledger automatically.

---

### 📌 Bill-by-Bill Adjustment
- Used for:
  - Against Reference
  - Due Amount Settlement

---

### ✂️ Split Entries
- Split a single entry into multiple ledgers.
- Continue until the **remaining value becomes zero**.
